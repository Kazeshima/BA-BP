# 使用指南

[English](user-guide.md) · **简体中文**

本指南面向使用 BA 禁选工具主持比赛禁选的主办方。

## 界面布局

| 区域 | 用途 |
|---|---|
| **顶栏** | 撤销 / 重做、特殊规则、自由 / 保护侧栏、存档、局间重置、完全重置、语言、主题、全屏、设置 |
| **禁用栏** | 攻击方禁用（左）、共享禁用（中间，金色）、防守方禁用（右） |
| **学生列表** | 所有已实装学生，支持搜索和筛选 |
| **自由 & 保护侧栏** | 保护位和自由学生列表 |
| **出战面板** | 玩家头像和名称、阵容模式切换、每方 6 个出战槽位 |
| **记分板** | 比分、交换双方、选择计时 |

## 禁选操作

把学生从列表（或侧栏）**拖动**到槽位上。拖动时，每个槽位都会显示能否放入该学生：**绿色** 表示可以放入，变暗表示不可以。放到不合法的槽位时，会提示原因。

| 操作 | 方法 |
|---|---|
| 禁用 / 选择 | 从列表拖到槽位 |
| 移动 / 交换 | 把槽位里的学生拖到另一个槽位；目标有人时两者交换 |
| 移除 | 把学生拖回列表、**右键** 槽位，或悬停后点击 **×** |
| 撤销 / 重做 | `Ctrl+Z` / `Ctrl+Shift+Z`（或 `Ctrl+Y`），也可点顶栏的箭头按钮 |

已禁用的学生在列表中变灰，无法拖动。已选择的学生会显示对应颜色的 **攻** / **守** 标记。

### 普通模式下的规则

- 每名学生只能被禁用一次（攻击方、防守方、共享禁用合计）。
- 已禁用的学生不能出战。
- 每名学生只能被一方选择一次。
- **4+2** 模式下，标 **主** 的槽位只能放主力（Striker），标 **援** 的槽位只能放支援（Special）。切换到 **6 通用** 后可以任意搭配。
- **保护位** 中的学生永远不能被禁用，开启特殊规则也不行。

### 阵容模式

每方都有 `4+2` / `6 通用` 切换按钮。从 6 通用切回 4+2 时，会自动把主力排到主力位、支援排到支援位；仍然放不下的会以红色高亮。

### 自由学生

自由学生（★）可以被双方重复选择，被禁用后仍可出战，并且可以放入任意槽位。在侧栏搜索添加，或右键学生选择 **设为自由学生**。默认的自由学生是白子（泳装），与 v1 一致。

### 保护位

把学生拖入侧栏的 4 个保护位，或右键学生选择 **加入保护位**。保护位中的学生不能被禁用。把保护位学生拖到出战槽位时是复制，她仍然保持受保护。保护位在两种重置后都会保留。

### 特殊规则

**特殊规则** 允许把任意学生放入任意槽位，适用于表演赛或需要手动处理的特殊情况。开启期间，按普通规则不合法的槽位会以红色高亮。只有阵容重新合法后才能关闭特殊规则，否则会提示是什么阻止了关闭。

## 局间操作

| 按钮 | 清除 | 保留 |
|---|---|---|
| **局间重置** | 双方各自的禁用、双方阵容 | 共享禁用、比分、名称、保护位 |
| **完全重置** | 所有禁用、双方阵容、计时、比分 | 名称、头像、保护位、设置 |

两者都可以用 `Ctrl+Z` 撤销。点记分板上的 **⇄** 可交换双方玩家（名称、头像、比分）。

## 比分和计时

- 点击比分可直接输入，或悬停后点 **+** / **−**。
- 设置计时秒数后点 **开始**（或按 `空格`）。暂停后继续会从剩余时间接着计时。
- 剩余 30 秒变金色、10 秒变红色；最后 5 秒有提示音，归零时响铃。提示音可在设置中关闭。
- 按 `R` 重置计时。

## 玩家信息

在双方阵容上方输入玩家名称。点击圆形头像（或把图片文件拖到头像上）即可设置头像。头像会被缩放后保存，重启后依然保留。

## 列表筛选

- **搜索** 支持本地化名称、英文内部名、学生 ID 和 SchaleDB 别名（`Ctrl+F` 聚焦搜索框，`Esc` 清空）。
- 可按 **主力 / 支援**、**职能**、**攻击类型**、**防御类型** 筛选，多个职能或类型可以同时选中。
- **隐藏已禁** / **隐藏已选**：随着禁选推进缩小候选范围。
- 拖动滑块可调整卡片大小。

### 存档

右键学生选择 **移入存档**，可以把她从主列表中彻底隐藏，适合处理被永久禁止的学生。点顶栏的 **存档** 可以搜索或取回已存档的学生。

## 设置

| 设置项 | 说明 |
|---|---|
| 界面语言 | 中文 / English，也可点顶栏的 中/EN 按钮切换 |
| 主题 | 跟随系统、明亮、暗色 |
| 学生名称语言 | 学生名称使用哪种 SchaleDB 翻译 |
| 服务器 | 只显示在日服、国际服或国服实装的学生 |
| 每方禁用槽 / 共享禁用槽 | 每方 0–10 个，共享 0–80 个 |
| 计时提示音 | 开 / 关 |
| 学生数据 | 显示数据的更新时间；**刷新数据** 会重新获取 |

## 快捷键

| 按键 | 功能 |
|---|---|
| `空格` | 开始 / 暂停计时 |
| `R` | 重置计时 |
| `Ctrl+Z` | 撤销 |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 重做 |
| `Ctrl+F` | 聚焦搜索框 |
| `F11` | 全屏 |

## 直播建议

- 使用全屏（`F11`），在 OBS 中用窗口采集。暗色主题适合大多数直播画面。
- 网页版也可以作为 OBS 的「浏览器源」使用，但它的保存数据与桌面版相互独立。

## 离线使用与数据

首次加载成功后，学生列表会被缓存。无法访问 SchaleDB 时，程序会使用缓存数据并显示 **Offline** 标记。学生立绘从 SchaleDB 加载，并由浏览器引擎缓存。

所有数据都保存在本地（桌面版保存在 WebView2 存储中，网页版保存在浏览器存储中）。除了向 SchaleDB 请求学生数据，以及桌面版每天一次向 GitHub 检查新版本外，不会向任何地方发送数据。

## 常见问题

| 问题 | 解决方法 |
|---|---|
| 「学生数据加载失败」 | 确认能访问 `schaledb.com`，然后点 **重试** |
| 新学生没有出现 | 设置 → **刷新数据**，并检查 **服务器** 设置 |
| 学生放不进槽位 | 查看窗口顶部的提示；确实需要时可开启 **特殊规则** |
| 无法关闭特殊规则 | 先修正红色高亮的槽位 |
